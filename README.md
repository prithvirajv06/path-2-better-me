## 9. Revision strategy

Use the 1–3–7–14–30 revision cycle.

| Day    | Revision activity           |
| ------ | --------------------------- |
| Day 1  | Learn and implement         |
| Day 3  | Recall without notes        |
| Day 7  | Solve a new problem         |
| Day 14 | Explain and implement again |
| Day 30 | Apply to a project          |

Maintain a learning journal containing:

- Concepts learned.
- Code implementations.
- Problems solved.
- Mistakes and corrections.
- Questions you cannot answer.
- Topics requiring revision.
